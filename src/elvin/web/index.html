Каждое условие передаётся Gemini дословно как описание соответствующего tool. Backend не дописывает скрытые правила классификации. «Недозвон» определяется технически без участия Gemini.

Завершение звонка со стороны робота

Заполненное поле объявляет Gemini tool end_call. Укажите здесь все условия, момент вызова и необходимость сначала попрощаться. Пустое поле полностью отключает автоматическое завершение.

Вставить ссылку на условие стадии:

Короткие «ага», «угу», «да-да» не прерывают робота и не отправляются в Gemini. Решение принимается локально по накопленному времени речи.

После подтверждения полноценной реплики робот продолжает говорить заданное время и только затем освобождает линию для собеседника.

При подтверждённом перебивании громкость текущей реплики плавно снижается к концу речевого хвоста. Следующий ответ всегда начинается с обычной громкостью. Эффект работает совместно с отсрочкой перебивания.
